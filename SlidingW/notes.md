# Sliding Window Technique - Mastery Guide

## 📚 Introduction to Sliding Window

The Sliding Window technique is used for problems involving arrays, strings, or linked lists where we need to find a subrange satisfying certain conditions. 

## Two Types of Sliding Windows:
1. **Fixed Window Size** - Window size is predetermined
2. **Variable Window Size** - Window expands/contracts based on conditions

### Pattern Templates

#### 🧱 Fixed Window Template
```cpp
#include <vector>
#include <numeric>
#include <algorithm>

int fixed_window(const std::vector<int>& arr, int k) {
    // If the array is smaller than the window size, return 0 (or handle as needed)
    if (arr.size() < k) return 0;

    // Calculate the sum of the first 'k' elements
    int window_sum = std::accumulate(arr.begin(), arr.begin() + k, 0);
    int result = window_sum;

    // Slide the window across the rest of the array
    for (size_t i = k; i < arr.size(); ++i) {
        window_sum += arr[i] - arr[i - k];
        result = std::max(result, window_sum);
    }

    return result;
}

```

#### 🪗 Variable Window Template
```cpp
#include <vector>
#include <algorithm>
#include <climits>

int variable_window(const std::vector<int>& arr, int target) {
    int left = 0;
    int current_sum = 0;
    
    // INT_MAX is the C++ equivalent of float('inf')
    int min_length = INT_MAX; 

    for (int right = 0; right < arr.size(); ++right) {
        current_sum += arr[right];

        // Shrink the window from the left while the condition is met
        while (current_sum >= target) {
            min_length = std::min(min_length, right - left + 1);
            current_sum -= arr[left];
            left += 1;
        }
    }

    // Return 0 if no valid window was ever found
    return (min_length != INT_MAX) ? min_length : 0;
}

```

## 📝 Tips for Success

1. **Always start with brute force** - It helps understand the problem
2. **Identify window expansion/contraction conditions clearly**
3. **Draw diagrams** for complex problems
4. **Practice both fixed and variable windows** separately before mixing
5. **Pay attention to edge cases**: empty array, single element, all same elements
6. **Optimize space complexity** when possible (often O(1))
7. **Use hash maps** for frequency counting within windows
8. **Consider two-pass solutions** for complex constraints
9. **Deque is your friend** for maximum/minimum in window problems
10. **Time complexity should typically be O(n)** for sliding window problems
